# Geist Sans

`geist-latin.woff2` is the unmodified Latin variable font bundled with
Next.js 16.4.0 at `next/dist/next-devtools/server/font/geist-latin.woff2`.
It is stored locally so production builds do not need to fetch Google Fonts.

Font project: https://github.com/vercel/geist-font
